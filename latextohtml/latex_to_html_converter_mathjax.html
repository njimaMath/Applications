Conversion from LaTeX to HTML

Paste a LaTeX source file, render it with MathJax, and export a standalone HTML document.

This is a lightweight converter: it styles sections, theorem-like environments, itemize, and the bibliography. Mathematical expressions remain in TeX and are typeset by MathJax. Cross-references are improved: theorem/section references are resolved, and equation references use MathJax labels.

Note: MathJax is loaded from a public CDN. The exported HTML file will typeset math when opened with an internet connection.
